VESSEL LOGGER - USB DEPLOYMENT PACKAGE
=======================================

QUICK START:
1. Insert this USB drive into vessel computer
2. Double-click 'start-vessel-logger.bat' 
3. Wait for browser to open automatically
4. Follow setup wizard on first use

REQUIREMENTS:
- Windows 10/11 (64-bit)
- 4GB RAM minimum
- Administrator privileges may be required

SUPPORT:
- User Manual: docs\USB_DEPLOYMENT_GUIDE.md  
- Troubleshooting: See documentation folder
- Emergency: Contact vessel IT administrator

IMPORTANT:
- Do not remove USB while system is running
- Always use 'stop' before ejecting USB drive
- Keep USB drive secure when not in use
